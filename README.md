# QR Code Generator

A lightweight, client-side QR code generator that runs directly in your browser.

## Features

- Generate QR codes from URLs
- Client-side QR generation
- No backend required
- No database required
- Download QR code as PNG
- Responsive interface
- Simple and lightweight

## Demo

[Live Demo](YOUR-GITHUB-PAGES-URL)

## How It Works

The application processes the entered URL directly in the browser
and generates the QR code using JavaScript.

## Privacy

No URL needs to be sent to a backend server for QR generation.
